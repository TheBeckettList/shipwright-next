# The project

## In one paragraph

A Minecraft **Bedrock** add-on (behaviour pack + resource pack, Script API `@minecraft/server` 2.8.0,
`server-ui` 2.0.0, engine ≥ 1.21.90). It opens a dimension of its own, `waterworld:sea`, and lays it
chunk by chunk around the players from a world that already exists as math: a painted globe map, climate,
rivers, sea life, peoples and their history, and Thera (Strongyle) before the Bronze Age eruption as the
homeport where every player arrives. Nothing is vanilla-generated. Shipwright (boats from 20+ seafaring
traditions, plus the Therans' wing-rigged foiler/catamaran/trimaran and the League's galleys from S001, sailing physics, yards, crews, charts and treasure) is folded in as `scripts/ship/`.
Tested on a local Bedrock Dedicated Server in Docker and played from a Nintendo Switch over LAN.

## The layers

```
  the math (shared)            the world (pure)              the game (Minecraft)
  ─────────────────            ────────────────              ────────────────────
  core/field.js  golden F  ─▶  world/map.js   the globe  ─▶  game/ground.js  a column's top
  core/cycles.js pulse+record  world/climate.js heat, wet     game/strata.js  rock beneath
  core/clock.js  pisano ladder world/rivers.js  drainage      game/theranciv.js, cothon.js, skyway.js
  core/golden.js word, lattice world/thera.js   the island    lay.js  three passes per chunk
  core/reversible.js shears    world/sealife.js stocks        rings.js how far each pass reaches
  core/boat.js   a hull        world/solar.js   the rite      tempo.js duties on the 200-tick bar
  core/sea.js, wind.js, globe.js …                            main.js  commands, events, players
                                                              ship/   Shipwright: boats, yards, crew
                       ▲
                       │ baked offline by tools/buildmod.mjs (Node)
                  data/*.js  (map, terrain, city, structures, folk, grown, faith) ≈ 48 MB
```

- **core/** is pure: no Minecraft imports, no free numbers (see `CONVENTIONS.md`). It is the part all three
  of you share with the physics work (see `MATH.md`).
- **world/** turns the painted map plus core laws into fields (climate, rivers, biomes, sea life).
- **game/** turns fields into blocks. `game/ground.js` is shared by the bake (Node) and the game, so a
  placement worked out offline lands on the ground the game lays.
- **data/** is *build output*. It is regenerated by the bake tools; hand edits are lost.
- **ship/** is Shipwright. It keeps its own steering/projection and takes its hull physics from
  `core/boat.js` via `ship/ourmath.js`. Shipwright's own sea dimension, pregen and Therans are switched off
  in this build: Waterworld lays the world.

## How the world reaches a player

1. A player joins → taken to `waterworld:sea`, arriving at the Sea Rite Temple on Thera.
2. `rings.js` scores every chunk near a player (Fibonacci rings: deep 5, folk 8, surface 13 chunks).
3. `lay.js` lays chunks in three passes, cheapest-and-nearest first: **surface → life → deep**. Each pass
   marks the chunk on the world floor when done, so a restart resumes where it stopped.
4. Beyond 13 chunks, `pregen` lays the world outward from Thera in the background. What lives out there
   is closed-form (asked at any tick, never stepped) until someone comes near.
5. `probe.js` writes `[WWPROBE] {json}` lines to the server log; `ww probes` collects them for
   `tools/calibrate.mjs`, which may move a knob in `game/calibration.js` one Fibonacci rung at a time.

## The dev kit (`ww`)

macOS + Docker Desktop (Rosetta on Apple Silicon) + `itzg/minecraft-bedrock-server`, LAN-visible for a
Switch. First time: unzip `waterworld-dev.zip` to `~` and run `bash ~/waterworld/ww setup`.

| Command | Does |
|---|---|
| `ww update` / `ww update --new` | install the newest `~/Downloads/waterworld-update*.zip` (packs **replaced** wholesale), keep / wipe the world |
| `ww status`, `ww watch`, `ww errors`, `ww stats` | is it up; live log; errors; chunk timings |
| `ww soak [n]`, `ww fly [b/s] [s] [deg]` | server tours its test sites / flies a test path and counts holes, then `ww probes` |
| `ww probes`, `ww report` | measurements / full debug report → Desktop + clipboard, for the chat |
| `ww cmd <text>` | server console command |
| `ww pregen on/off/status/reset` | the background lay of the whole world |
| `ww new` | **destructive**: deletes old Shipwright/Waterworld containers and worlds (see ISSUES I-005) |

In-game: `/scriptevent waterworld:go temple|harbour|…|<x> <z>`, `waterworld:where`, `waterworld:radius n`,
`waterworld:version`; ship side `shipwright:check` (self-checks), `shipwright:selftest`,
`shipwright:showcase`, `shipwright:cleanup`, and the calibration commands in `ship/devtools.js`.
